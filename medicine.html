第一篇

黄芪与黄芩：亲兄弟还是陌路人？——教你分辨这两种“黄氏”中药

黄芩（《本经》中品）
  • 一、基本信息
  • - 别名：腐肠、妒妇、片芩、宿芩等。
  • - 释名：〔时珍曰〕芩《说文》作菳，因色黄得名；又因旧根多中空、外黄内黑（即片芩），类比“腐肠”（中空如肠）、“妒妇”（心黯如妒妇性情）而得别名。

    二、产地与采收
  • >- 产地：《别录》载“生秭归川谷及冤句”（今湖北、河南等地），现主产于河北、山西、内蒙古等。
  • - 采收：三月三日采根，阴干；现代多在春、秋二季采挖，除去须根和泥沙，晒后撞去粗皮。
  • 三、性味归经
  • - 气味：苦，平，无毒（古籍记载）；现代中医认为其性寒，归肺、胆、脾、大肠、小肠经。
  • 四、功效主治
  • 功效1. 清热燥湿：可用于湿温、暑湿，湿热痞满，泻痢，黄疸等病症。能清除中焦、上焦的湿热，比如湿热引起的胸闷、恶心、呕吐，或者大肠湿热导致的腹泻、痢疾等。
  • 2. 泻火解毒：善于清肺火及上焦实热，可用于治疗肺热咳嗽，高热烦渴等。同时，对于痈肿疮毒也有一定的治疗作用，能解毒消肿。
  • 3. 止血：可用于血热妄行所致的吐血、衄血、便血、崩漏等出血症。 4. 安胎：能用于胎热不安，有清热安胎的功效。 主治 1. 湿温、暑湿证，症见胸闷呕恶、身热不扬等。 2. 湿热痞满、泻痢、黄疸，如湿热阻滞中焦引起的脘腹痞闷、恶心呕吐，以及湿热下注导致的泻痢、黄疸等。 3. 肺热咳嗽，表现为咳嗽气喘、痰黄黏稠等。 4. 高热烦渴，属气分实热者。 5. 痈肿疮毒，可内服或外用。 6. 血热出血证，如吐血、衄血、便血、崩漏等。 7. 胎热不安，孕妇因胎热出现的胎动不安等情况。（一）古籍记载 1. 《本经》：主诸热黄疸，肠澼，泄利，逐水，下血闭，恶疮，疽蚀，火疡。 2. 元素：凉心，治肺中湿热，泻肺火上逆，疗上热，目中肿赤，瘀血壅盛，上部积血，补膀胱寒水，安胎，养阴退阳。 3. 时珍：治风热湿热头疼，奔豚热痛，火咳肺痿喉腥，诸失血。 4. 《别录》：治肠澼脓血。 （二）现代中医总结 清热燥湿，泻火解毒，止血，安胎。用于湿温、暑湿，胸闷呕恶，湿热痞满，泻痢，黄疸，肺热咳嗽，高热烦渴，血热吐衄，痈肿疮毒，胎动不安。 五、炮制与用法 - 炮制： - 生黄芩：切片晒干，长于清热泻火。 - 酒黄芩：黄芩片加黄酒炒制，增强清上焦热之力。 - 炒黄芩：文火炒至微焦，缓和苦寒之性。 - 黄芩炭：炒至焦黑色，用于止血。 - 用法禁忌：煎服，3-10g；脾胃虚寒者忌用，忌与山茱萸、龙骨、葱实等配伍（古籍“相恶相反”记载）。 六、附方精选（古籍实用方） 1. 三补丸（《丹溪纂要》）：黄芩、黄连、黄檗等分，蒸饼丸，治上焦积热、五脏火盛。 2. 肝热生翳方（《卫生家宝方》）：黄芩一两、淡豉三两为末，熟猪肝裹服，治大人小儿肝热目翳。 3. 少阳头痛方（东垣《兰室秘藏》）：酒浸片黄芩晒干为末，茶酒送服，治少阳（或太阳）头痛。 4. 胎动不安方（《简便方》）：胡黄连末，米饮服，治五心烦热型胎动。 七、药材性状 - 根呈圆锥形，扭曲，长8-25cm，直径1-3cm；表面棕黄色或深黄色，有稀疏的疣状细根痕，上部较粗糙，有扭曲的纵皱纹或不规则的网纹，下部有顺纹和细皱纹。 - 质硬而脆，易折断，断面黄色，中心红棕色；老根中心呈枯朽状或中空，暗棕色或棕黑色。气微，味苦。
